## 首版用户流程

1. 首次打开：电视键盘或扫码打开的临时局域网页面输入服务地址。优先 HTTPS，使用 HTTP 需用户明确选择。验证 `/api/server-config` 与必需接口，报告服务版本与存储模式。
2. 登录：电视显示二维码，手机在同一服务实例完成登录并确认；电视获取会话。普通账号密码登录作为备用。服务启用 Turnstile 时引导手机登录再扫码。会话到期时刷新，失效时重新登录。
3. 内容：浏览电影、剧集、动漫、综艺；搜索、详情、选集、收藏和继续观看。应用用服务端可用普通点播源列表过滤搜索结果，不把尚不支持的特殊来源呈现为可播放内容。
4. 播放：多个源并行测速，整个选源过程最多 5 秒；选已测得的最快可用源，若无结果按服务端顺序尝试。播放页允许手动换源。Media3 播放 HLS、MP4、FLV，支持流内字幕轨、遥控器播放控制、续播和进度保存。
5. 数据：服务端存储模式使用收藏与播放记录 API 双向同步；浏览器 localStorage 模式在电视本机保存并提示不能跨设备同步。本机数据按服务地址和用户隔离。
6. 更新：读取公开 GitHub Releases，下载与当前应用 ID 对应的签名 APK，校验文件后调起 Android 系统安装界面。安装由用户确认。

## 首版验收

- Android 6 及以上的目标电视或遥控器盒子可安装、启动并仅用方向键/确认键完成主要观看流程。
- 一台服务端存储模式的 MoonTVPlus `225.1.0` 实例可完成连接、扫码登录、搜索、详情、选集、播放、续播、收藏与网页同步。
- 一台 localStorage 模式实例可完成登录、播放和本机数据保留；切换服务或账号后数据不串用。
- 使用可控样本分别验证 HLS、MP4、FLV 与流内字幕轨；不支持的容器、编码或失效源给出可理解的错误与换源入口。
- 5 秒选源上限、连接失败、认证过期、服务版本不兼容、下载失败及安装取消都有可恢复的交互。
- 发布签名密钥从备份恢复后可签出与先前版本兼容的更新包；签名材料不进入 Git 仓库。

## 范围边界

应用只做播放端。首版不做管理、直播、私人影库、网盘特殊来源、弹幕、外挂字幕、离线下载或日常手机遥控。

## 需要真实环境验证的风险

- 自部署实例的具体源与媒体编码差异会影响三种格式在不同电视芯片上的表现。
- 某些实例的播放地址、代理和媒体分片可能需要会话 Cookie 或服务端特殊请求头，需用真实源验证。
- GitHub Releases 的网络可达性和 Android 设备的安装来源权限因用户设备而异。
