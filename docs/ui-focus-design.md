# 全应用遥控器焦点优化

## 状态

2026-09-26：用户确认方案并授权实施；应用代码已修改，Debug APK 构建通过。

## 问题与范围

详情页选集按钮的遥控器焦点主要依靠背景轻微变亮区分，远距离观看时不够明显。现有按钮、卡片、输入框和播放菜单的焦点反馈也不一致。

优化覆盖连接服务、登录、首页、搜索、详情、全屏播放和设置中的可交互控件。

## 已确认的视觉方向

用户选择方案 A：保留深色与紫色主题，遥控器焦点采用白色粗边框和背景提亮，影片卡片适度放大。

- 焦点边框目标宽度为 3 dp，并沿控件外形绘制。
- 按钮、影片卡片、输入框、预览窗口和全屏播放菜单使用一致的焦点反馈。
- 放大后的影片卡片须预留空间，避免被容器裁剪或覆盖邻项。

## 已确认的状态规则

- 当前播放集使用紫色背景和播放标记；当前播放源使用紫色背景和勾选标记。
- 遥控器移向其他集数或来源时，当前播放状态仍保持显示，焦点独立使用白色边框和提亮背景。
- 按确定才执行选集或换源；执行后焦点所在项同时显示当前状态与焦点边框。
- 暂停时保留当前播放集的归属，播放标记用于表示当前集，不表示播放器一定正在输出画面。
- 换源失败时保留原当前源标记。

## 最终实施方案提案

- 覆盖连接服务、登录、首页、搜索、详情、全屏播放和设置的全部应用内交互控件。
- 首页两排标签沿用焦点移入即切换内容的行为，当前标签保留紫色背景；焦点独立显示白色边框。
- 普通按钮和输入框增加一致的焦点反馈；输入框保留浅色文字并增强边框及背景对比。
- 影片卡片焦点适度放大，并检查网格边缘、滚动时的裁剪与邻项遮挡。
- 预览窗口、收藏按钮、全屏操作图标和全屏选集/换源面板遵循相同的视觉规则。
- 不可用操作降低亮度且方向键跳过；保持首集、末集的上一集/下一集禁用行为。
- 构建 Debug APK，使用可用的 Android TV 模拟器核对遥控器操作与截图，记录实际验证范围。

## 代码核对

- 详情页和全屏面板目前都需要按确定键才执行选集、换源。
- 首页两排标签目前在焦点移入时切换内容。
- 全屏菜单与面板通过父容器处理方向键，并用索引表示当前指向的操作。

本次视觉优化保留这些既有操作行为。

## 实施与验证

- 共用电视按钮和输入框统一使用白色 3 dp 焦点边框、提亮背景和清晰文字。
- 首页与搜索卡片增加焦点放大、绘制顺序与网格留白。
- 详情页当前播放集与当前播放源有持续标记；全屏面板的方向键焦点和当前播放状态分别显示。
- 搜索、连接、登录及设置页进入后给首个操作明确焦点。
- `./gradlew :app:assembleDebug` 通过；APK 已安装到 Android TV 模拟器，逐键核对首页栏目焦点，并截图核对搜索输入框焦点。
